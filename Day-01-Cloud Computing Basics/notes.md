\# Day 01 - Cloud Computing Basics



\## Cloud Deployment Models



\### 1. Public Cloud



The cloud infrastructure is owned and managed by a third-party cloud provider. Resources are shared among multiple customers.



\*Examples\*

\- Amazon Web Services (AWS)

\- Microsoft Azure

\- Google Cloud Platform (GCP)



\*Advantages\*

\- Low cost

\- Easy to scale

\- No hardware maintenance



\---



\### 2. Private Cloud



Infrastructure is dedicated to a single organization.



\*Advantages\*

\- Higher security

\- Better control

\- Suitable for organizations handling sensitive data



\---



\### 3. Hybrid Cloud



A combination of public and private cloud environments.



Organizations can keep sensitive data on a private cloud while using the public cloud for less critical workloads.



\*Example\*



\- Banking systems

\- Healthcare organizations



\---



\### 4. Community Cloud



Infrastructure is shared by multiple organizations with similar security or compliance requirements.



\*Example\*



Government departments sharing a common cloud infrastructure.



\---



\# Characteristics of Cloud Computing



\## On-Demand Self-Service



Users can provision resources whenever needed without human intervention.



\---



\## Broad Network Access



Cloud services are accessible from anywhere using the internet.



\---



\## Resource Pooling



Cloud providers serve multiple customers using shared infrastructure while securely isolating resources.



\---



\## Rapid Elasticity



Resources can scale up or down automatically depending on demand.



\---



\## Measured Service



Users pay only for the resources they consume.



\---



\# Advantages of Cloud Computing



\- Cost-effective

\- Highly scalable

\- Faster deployment

\- High availability

\- Global accessibility

\- Better disaster recovery

\- Reduced infrastructure maintenance



\---



\# Real-World Example



An e-commerce website experiences heavy traffic during festive sales.



Instead of purchasing expensive servers for the entire year, the company scales cloud resources only during peak demand and scales them back afterward.



This reduces costs while maintaining application performance.
